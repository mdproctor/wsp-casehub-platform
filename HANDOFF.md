## Architecture Decisions (this session)

- **Generator handles Consumer/Optional/List patterns.** POJO constructor following resolves all three CDI bridging patterns. Beans with @ConfigProperty→@Value, qualified injection (@WorkerBackend, @VirtualThreads), setter injection, or factory switches must remain hand-written.
- **swarmProvisioner uses @ConditionalOnBean.** Quarkus fails-to-create when deps missing; Spring equivalent is conditional guard.
- **EntityNotFoundException moved to engine-api.** Domain exception belongs in the API module, not the REST layer — both JAX-RS and Spring need it.
