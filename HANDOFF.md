## Architecture Decisions (this session)

- **@Transactional on POJOs + CDI boundary:** @Transactional stays on POJOs for Spring compatibility. In Quarkus, @Transactional fires at the EngineAdapterBeans observer/consumer method level (CDI boundary), not on the POJO itself (produced beans don't get interceptors).
- **EventBus → Consumer<T>:** POJO takes Consumer<T>, CDI wiring creates lambda `e -> eventBus.publish(ADDRESS, e)`. For Spring: ApplicationEventPublisher.
- **@ConsumeEvent → field reference in beans:** @ConsumeEvent methods only accept the event payload parameter (unlike CDI observers which support injection points). Handler injected as @Inject field on EngineAdapterBeans.
- **engine#1209 and #1210 closed as already-resolved / not-needed.** MCP Spring already in engine-support-spring; persistence-spring-jpa hand-written for good reason.
