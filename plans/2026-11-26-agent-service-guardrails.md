# @AgentService + Guardrails Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> subagent-driven-development (recommended) or executing-plans to
> implement this plan task-by-task. Each task follows TDD
> (test-driven-development) and uses ide-tooling for structural
> editing. Steps use checkbox (`- [ ]`) syntax for tracking.

**Focal issue:** #984 — Declarative Agent Invocation — @AgentService + Guardrails
**Issue group:** #983, #985, #988

**Goal:** Deliver type-safe declarative agent invocation (`@AgentService`) and cross-cutting content guardrails, with prompt caching parity.

**Architecture:** APT-generated proxy classes delegate to `AgentProvider` for invocation and `AgentResolver` for descriptor resolution. Guardrails are CDI decorators on `AgentProvider` at priorities below the existing gate. The APT follows the `GraphQLResolverProcessor` pattern. All new SPIs and annotations go in `agent-api`. Caching parity wires existing SDK features through the platform's mapper layer.

**Tech Stack:** Java 21, Quarkus 3.32.2, Mutiny (`Multi<AgentEvent>`), Jandex + JavaPoet (APT), LangChain4j 1.19.0 (ToolSpecification), Anthropic Java SDK, OpenAI Java SDK

## Global Constraints

- `agent-api` must remain zero casehubio dependencies (Mutiny is an existing external dep)
- All new annotations use `@Retention(RUNTIME)` for Jandex visibility
- Generated proxy classes are framework-neutral — constructor injection only, no CDI/Spring imports
- Follow the `-core`/Quarkus/`-spring` pattern: `agent-service-generator` generates source, `agent-service` wires CDI, `agent-service-spring` is generated by `spring-generator`
- Guardrail decorators use `@Priority(1400)` (input) and `@Priority(1600)` (output), both before the gate at `@Priority(2000)`
- TDD: every task writes a failing test first
- Commit after every task

```java
package io.casehub.platform.agent.guardrail;

import io.casehub.platform.agent.AgentEvent;
import io.casehub.platform.agent.AgentSessionConfig;
import io.smallrye.mutiny.Multi;
import java.util.List;
import java.util.function.Function;

public final class GuardrailStreamOperator {

    private GuardrailStreamOperator() {}

    public static Multi<AgentEvent> validate(
            Multi<AgentEvent> source,
            List<OutputGuardrail> guardrails,
            AgentSessionConfig config,
            int maxReprompts,
            Function<String, Multi<AgentEvent>> repromptFn) {

        return source.collect().asList()
            .onItem().transformToMulti(events -> {
                String text = events.stream()
                    .filter(e -> e instanceof AgentEvent.TextDelta)
                    .map(e -> ((AgentEvent.TextDelta) e).text())
                    .reduce("", String::concat);

                for (OutputGuardrail guardrail : guardrails) {
                    GuardrailResult result = guardrail.validate(text, config);
                    switch (result) {
                        case GuardrailResult.Pass p -> {}
                        case GuardrailResult.Fail f ->
                            throw new GuardrailException(f.reason());
                        case GuardrailResult.Reprompt r -> {
                            if (maxReprompts <= 0) {
                                throw new GuardrailException(
                                    "Max reprompts exceeded: " + r.repromptMessage());
                            }
                            return validate(
                                repromptFn.apply(r.repromptMessage()),
                                guardrails, config, maxReprompts - 1, repromptFn);
                        }
                    }
                }
                return Multi.createFrom().iterable(events);
            });
    }
}
```

```java
@Decorator @Priority(1400)
public class InputGuardrailDecorator implements AgentProvider {
    @Inject @Delegate AgentProvider delegate;
    @Inject Instance<InputGuardrail> guardrails;

    @Override
    public Multi<AgentEvent> invoke(AgentSessionConfig config) {
        for (InputGuardrail g : guardrails) {
            GuardrailResult result = g.validate(config);
            switch (result) {
                case GuardrailResult.Pass p -> {}
                case GuardrailResult.Fail f ->
                    return Multi.createFrom().failure(new GuardrailException(f.reason()));
                case GuardrailResult.Reprompt r ->
                    return Multi.createFrom().failure(
                        new GuardrailException("Input reprompt not supported: " + r.repromptMessage()));
            }
        }
        return delegate.invoke(config);
    }

    @Override
    public AgentSession openSession(AgentSessionInit init) {
        return delegate.openSession(init);
    }
}
```

```java
@Decorator @Priority(1600)
public class OutputGuardrailDecorator implements AgentProvider {
    @Inject @Delegate AgentProvider delegate;
    @Inject Instance<OutputGuardrail> guardrails;

    @ConfigProperty(name = "casehub.guardrail.output.max-reprompts", defaultValue = "3")
    int maxReprompts;

    @Override
    public Multi<AgentEvent> invoke(AgentSessionConfig config) {
        Multi<AgentEvent> stream = delegate.invoke(config);
        if (guardrails.isUnsatisfied()) {
            return stream;
        }
        List<OutputGuardrail> sorted = guardrails.stream().toList();
        return GuardrailStreamOperator.validate(
            stream, sorted, config, maxReprompts,
            reprompt -> delegate.invoke(AgentSessionConfig.of(config.systemPrompt(), reprompt)
                .withModel(config.model())
                .withResponseFormat(config.responseFormat()))
        );
    }

    @Override
    public AgentSession openSession(AgentSessionInit init) {
        return delegate.openSession(init);
    }
}
```

```java
@ApplicationScoped
public class MaxTokenInputGuardrail implements InputGuardrail {
    @ConfigProperty(name = "casehub.guardrail.max-input-tokens", defaultValue = "100000")
    int maxTokens;

    @Override
    public GuardrailResult validate(AgentSessionConfig config) {
        int estimatedTokens = (config.userPrompt().length() + (config.systemPrompt() != null ? config.systemPrompt().length() : 0)) / 4;
        if (estimatedTokens > maxTokens) {
            return new GuardrailResult.Fail("Input exceeds maximum token limit: estimated " + estimatedTokens + " > " + maxTokens);
        }
        return new GuardrailResult.Pass();
    }
}
```

```java
@ApplicationScoped
public class JsonSchemaOutputGuardrail implements OutputGuardrail {
    @Override
    public GuardrailResult validate(String response, AgentSessionConfig originalConfig) {
        if (originalConfig.responseFormat() == null || originalConfig.responseFormat().type() == ResponseFormatType.TEXT) {
            return new GuardrailResult.Pass();
        }
        try {
            new com.fasterxml.jackson.databind.ObjectMapper().readTree(response);
            return new GuardrailResult.Pass();
        } catch (Exception e) {
            return new GuardrailResult.Fail("Response is not valid JSON: " + e.getMessage());
        }
    }
}
```
